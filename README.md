## 🚀 Features

- **⚡ Interactive Cyber Grid Canvas:** Dynamic node-connecting background particle animation responding smoothly in real-time.
- **⌨️ Matrix Typewriter Effect:** Continuous looping typewriter animation displaying custom text (`IC0NIC`).
- **🔊 Web Audio API Integration:** High-precision, synthesized digital click sound effects on link interactive events without relying on external `.mp3` files.
- **🎨 Glassmorphism & Cyber Aesthetics:** Modern visual hierarchy built with custom CSS CSS variables, glowing neon effects, and responsive navigation.
- **📱 Fully Responsive:** Optimized layout ensuring a seamless user experience across Desktop, Tablet, and Mobile devices.
